# Ambiente e operação

> **Para que serve:** clonar, instalar e rodar o cliente.
> **Fonte da verdade:** `package.json` e scripts do Vite.
> **Relacionados:** [context](context.md)

```bash
git clone git@github.com:joaolfern/serveruler-client.git
# ou o fork RafaelHDSV/serveruler-client
cd serveruler-client
yarn   # ou npm install
yarn dev
```

Detalhes de configuração e variáveis: ver `.env.example` se existir e o README legado movido para esta pasta ao longo do tempo.
